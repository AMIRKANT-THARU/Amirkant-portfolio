## 📝 How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AMIRKANT-THARU/Amirkant-portfolio.git
   ```

2. **Navigate to the project:**
   ```bash
   cd Amirkant-portfolio
   ```

3. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server like Live Server in VS Code

## 🌐 Deploy to GitHub Pages

To deploy this portfolio on GitHub Pages:

1. Go to your repository settings
2. Scroll to **GitHub Pages** section
3. Select `main` branch as source
4. Your site will be live at: `https://AMIRKANT-THARU.github.io/Amirkant-portfolio/`

## 🎨 Customization

### Change Colors
Edit the CSS variables in `styles.css`:
```css
:root{
    --accent: #2ecc71;           /* Main accent color */
    --text: #ffffff;              /* Text color */
    --dark-bg: #0a0a0a;          /* Background color */
}
```

### Update Content
- Edit text in `index.html`
- Replace `image.jpeg` with your profile photo
- Update social media links

### Modify Styling
- Edit `styles.css` for visual changes
- Adjust colors, fonts, spacing, animations
